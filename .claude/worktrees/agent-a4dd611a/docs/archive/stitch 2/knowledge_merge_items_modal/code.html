JWT rotation patterns

ID: K-39402 // UPDATED: 2023-11-24 14:22:10

Executive Summary

JSON Web Token (JWT) rotation is a security strategy where a new refresh token is issued every time the current one is used. This invalidates the old token, preventing unauthorized access if a token is intercepted. This pattern is essential for long-lived sessions in single-page applications (SPAs).
