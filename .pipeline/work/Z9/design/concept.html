[ // The Loop ]

Work flows as bets.

No workflows, no DAGs, no central planner. Sequences emerge from task dependencies — a bet carries a done condition, not a deadline.

SEC.02
01

Bet

Shaped work with an explicit done condition. draft → active → completed or killed.

02

Task

One agent's unit of work. Dependencies unlock the next step — nobody pre-wires the graph.

03

Session

One bounded run on a task. Ends at the context window; notes carry the next one forward.

04

Review

Where human judgment lands: approve, request changes, edit, reject.

Routines — recurring work with persistent memory · calendar / event / heartbeat triggers

[ // Ethos ]

Built against the enterprise default.

Four principles decide what we build and what we cut. They ship in the box.

SEC.04
01

Build for the fast, not the enterprise

No approval chains, no permission matrices, no governance theater. If a feature exists to reassure a risk-averse buyer who isn't ours, it gets cut.

02

Trust agents and humans

Agents act by default. Gates are earned from real outcomes, never built first — security is a learning, not a wall.

03

Boil the lake

AI makes completeness cheap. Test every path, read every doc — then stop at the edge of the task. Oceans aren't boilable.

04

Search before building

First principles over familiar patterns. Ask what the user actually needs before adding anything.

[ // Self-Host ]

Run it yourself.

Your machine, your keys, your data. HyperIdle self-hosts from a laptop to a cluster — five commands from clone to running app.

SEC.07 
$ git clone git@github.com:ambrovia/hyperidle.git
$ cd hyperidle
$ npm install
$ npm run setup -- --profile laptop   # PGlite + migrations + bootstrap
$ npm run dev                          # server :3001 + web :5173
Laptop

Embedded PGlite, zero infrastructure. Clone, set up, run — the profile above.

VPS

Postgres + Docker Compose on your own box. One compose file, your keys, your box.

Cloud

Managed Postgres, same code path. Point DATABASE_URL at it and deploy.

Prefer the app? Signed, notarized macOS build — brew tap ambrovia/homebrew-tap && brew install --cask hyperidle — or download the DMG. Agents run on the host in every profile.
