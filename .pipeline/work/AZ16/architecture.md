# AZ16 — Architecture

## Owners and integration

`framework/design-system/src/token-profiles.ts` owns the closed 14-role semantic typography registry and frozen inline exports `TYPE_STYLE`, `MOTION_STYLE`, and `BORDER_WIDTH_STYLE`; `tokens.css` owns matching `@utility` classes and keyframes. Raw profile fields are legal only in those two registry files.

ESLint owns `.ts/.tsx`: add `typography-profile-only`, `motion-profile-only`, and `border-width-profile-only`, reuse the existing class/style walkers, export them from the design plugin, and configure dynamically discovered production app/design-system packages at `error`. Promote raw Tailwind palette checks to `error` in both scopes. The existing rule ownership registry changes from one owner to a non-empty **set** of owners.

`motion-profile-only` also bans WAAPI, smooth scrolling, and arbitrary rAF. Its closed rAF allowance has exactly four call identities: RoleCombobox's one-frame focus, KnowledgeDetail's render-ready anchor scroll, and AppShell's route-restoration start plus bounded retry inside named `restore`; AppShell cleanup cancellation is required. The rule fails an added, moved, or structurally changed scheduling call.

CSS has no current PostCSS lint path. Add direct `postcss` dependency to `tools/repo-gates`, pure verdict code in `tools/repo-gates/src/lib/design-css-verdict.ts`, executable owner `tools/repo-gates/src/design-css-gate.ts`, root `lint:design-css`, and chain it in `npm run lint` after ESLint. It discovers production package CSS dynamically and hard-fails on zero files. It validates CSS profile consumption, rejects raw Tailwind palette/literal palette values outside the two exact foreign roots, proves the global reduced rule, exact token classification, and non-empty family owner sets. This is the live CSS gate; tests only exercise its pure verdict.

Add `tools/eslint-plugin-design/src/token-family-owners.ts` as the one shared registry consumed by the active ESLint config and imported by `tools/repo-gates`. Its owner sets are color→`no-hardcoded-color`,`no-raw-tailwind-color`; radius→`radius-token-only`; spacing→`no-off-grid-spacing`; shadow→`shadow-token-only`; z-index→`no-raw-overlay-z`; each five typography families→`typography-profile-only`; duration/easing→`motion-profile-only`; border-width→`border-width-profile-only`. `component-geometry` is an exact `non-family` registry entry with the reason “component-specific responsive bound, not reusable value vocabulary”; it needs no invented rule. Exact classification fails closed for zero/multiple classifications, an ownerless value family, or an unexplained non-family. All owners and severities are asserted from active config.

The two literal foreign roots receive `data-token-subject="foreign"`. The shared AST helper skips only color/typography/border declarations within those subtrees; it never hides siblings. Motion and global reduced mode do not skip foreign roots. TrafficLights remains owned.

## Deterministic migration

Treat the current three extractor outputs as **immutable pre-migration audit snapshots**. Stable identity is path + named scope + tag/kind + normalized-source fingerprint; duplicate suffixes are allowed only when every identical fingerprint has the same destination. Extractors write the `*-unmapped.tsv` report before failing, so a successful frozen audit has exactly one header line. CSS comment replacement preserves newlines.

Migration does not rerun source extractors against mutated code. `.pipeline/work/AZ16/audit-checksums.sha256` freezes all three manifests and all three decision maps; `.pipeline/work/AZ16/audit-checksum-gate.mjs` fails any byte drift. Each wave checks in `migration-receipts-<wave>.tsv` with the exact header `audit_site_id`, `audit_destination`, `outcome`, `profile`, `final_path`, `final_locator`. Every column is non-empty except `profile` where the mapping below requires it to be empty; `final_locator` is a stable exported/named symbol plus consumer kind, or for CSS a normalized selector plus enclosing at-rule identity, never a line number.

The exact outcome enum and mapping are: `PROFILE` for the 14 typography roles, seven motion profiles, and thin/default/strong border destinations, with `profile` exactly the destination; `NONE` for border NONE; `REMOVE` for any REMOVE; `SNAP` for motion SNAP; `GEOMETRY` for border GEOMETRY; `FOREIGN` for border FOREIGN; `GLYPH_REPAIR` for typography glyph-repair; and `HEADING_VARIANT` for the one typography heading-variant, with profile exactly `h1=display:1;h2=title:1;h3=lead:1;h4-h6=subheading:3`. `profile` is empty for NONE/REMOVE/SNAP/GEOMETRY/FOREIGN/GLYPH_REPAIR. `tools/repo-gates/src/az16-migration-receipt-gate.ts` fails missing, duplicate, unknown, invalid-enum, wrong/empty/unexpected profile, empty final target, or destination-incompatible receipts.

The separate final live census executable is `tools/repo-gates/src/design-profile-census.ts`, exposed as `npm run lint:design-profiles`, with schema `tools/repo-gates/src/design-profile-census.schema.json`. Its version-1 JSON is `{schemaVersion:1, discoveredPackages:string[], scannedFiles:string[], profiles:{typography:Record<Role,number>, motion:Record<MotionProfile,number>, border:Record<BorderProfile,number>}, rawByFamily:Record<OwnedFamily,number>, foreignByFamily:Record<ForeignFamily,number>, invalidProfileSites:{path:string,locator:string,reason:string}[]}`. Passing requires non-zero discovered packages/files; profile keys exactly equal the 14/7/3 registry keys; each owned PROFILE receipt total plus HEADING_VARIANT expansion equals its live profile count; typography must equal label116/metadata231/small232/copy48/control90/input11/avatar-initial14/subheading10/lead12/title11/display3/metric7/data99/inline-code2; all 13 owned value families are present in `rawByFamily` and equal zero; and `invalidProfileSites` is empty. Foreign counts remain reported and excluded; NONE/REMOVE/SNAP/GEOMETRY/FOREIGN/GLYPH_REPAIR are proven by receipt validation plus lint/E2E. This avoids pretending pre-migration identities survive their own edits.

Gate activation order keeps every build green: freeze the audit/checksums; land approved registries **and the global reduced-motion CSS**; land inactive lint/CSS/receipt/census verdicts; migrate each manifest leaf and add its receipt while current gates remain active; require complete receipts and a zero-raw live census; only then export/configure rules, add both design gates to root lint, and promote raw palette to error. Reduced mode therefore exists before any motion-profile gate activates.

## Delivery waves (<1,000 changed lines each)

The corrected manifests contain **1,259 unique source lines**: design-system 323, remaining core-ui 337, other pages 236, review pages 363. Generated audit/receipt row churn is evidence, not implementation size. Foundation and activation are split for headroom:

1. **Registry/reduced foundation** — semantic registries/classes, global reduced CSS, shared family-owner registry, receipt schema: **~500** (450–580).
2. **ESLint gate foundation** — inactive TS/TSX rules, shared walkers/config assertions, RuleTester fixtures: **~480** (420–560).
3. **CSS/receipt/census foundation** — PostCSS verdict, checksum/receipt gate, live-census executable/schema and fixtures: **~620** (540–720).
4. **Design-system migration** — 323 source lines plus receipt/component proof: **~670** (600–760).
5. **Core-ui migration** — 337 source lines plus receipt/focused tests: **~620** (560–700).
6. **Other-page migration** — 236 source lines plus receipt/route proof: **~480** (430–550).
7. **Review migration** — 363 source lines, receipts, exact foreign markers, Toast/14 rail repairs: **~720** (650–810).
8. **Gate activation** — active exports/config, CSS lint integration, raw-palette error, final live census: **~460** (410–530).
9. **Runtime proof/docs** — reduced-mode computed proof, owned Playwright matrix, painted snapshots, doc truth: **~590** (520–680).

Combined estimate is ~5,140 unique changed lines; no individual wave reaches 1,000. These are ordered leaves inside AZ16, not newly registered work packages. Reused machinery: existing ESLint visitors/config tests, root lint chaining, package discovery, Playwright route interception, and PostCSS AST. Removed assumptions: a broad runtime scanner, mutable audit identity, raw public ladders, exception framework, custom CSS parser, and broad motion/foreign carve-outs.

## Verification

The frozen audit is rerun once before migration and must byte-match its checked-in snapshots with header-only unmapped reports. Migration waves validate receipts, affected tests, check, and then-active lint. Final activation runs the receipt gate, live semantic census, `npm run check`, actual `npm run lint`, `npm run test`, the named AZ16 Playwright spec, and `npm run verify`.

`layers/core-ui/__e2e__/AZ16-token-profiles.spec.ts` owns all route mocks and fixture IDs (`t-az16`, `team-az16`, `bet-az16`, `k-az16`, `review-az16`), not shared global fixtures. It intercepts each route's API calls before navigation, provides loaded/loading/active-review states, performs the interactions that reveal settings, hover/focus/lift/press feedback, toggles, assistant entrance, skeleton/loading, activity, and busy states, and selects only `data-az16-profile` hooks added at profile consumers. Exact coverage: conversations→copy/small/metadata/data/control/avatar-initial + feedback/move/activity; team→label/avatar-initial/metric + strong border; bet→lead/title/avatar-initial + move/thin; knowledge→h1 display, h2 title, h3 lead, h4–h6 subheading, inline-code, separators, and auto scroll; settings→input/spring/mobile; review→display/subheading/metric/avatar-initial + independent opacity-feedback/transform-move, snap press, enter/loading/busy/Toast/default and foreign root. Actual motion states assert computed properties before/after interaction. Every approved named profile appears in at least one computed assertion and one light/dark painted snapshot; reduced mode repeats full-document and foreign-root assertions for `animationName:none`, `transitionProperty:none`, and auto scroll.
