# AF3 — Concept

No new primitive — type-debt drain. AF3 fixes type errors in existing `@hyperidle/fabric` services and tests; every noun (Block, Event, Routine, Session, Dirent, ThreadMessageAppendedEvent) is a stable existing concept used as-is.

Concept-level decision: no contract is reshaped here. A fix that would change a contract's *shape* (runtime behavior) is deferred to the owning functional workpackage (AF6–AF9) via a Z8-NNN register entry, not redefined in this workpackage.
