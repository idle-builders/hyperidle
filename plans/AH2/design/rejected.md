# Rejected directions (routine — considered, not built)

- **X — Provider control per agent (two axes: Provider `Select` + Model `Select`).** Rejected: every AH2 catalog entry is `anthropic`, so a provider control is a dead field that adds a second axis the founder doesn't need. Concept scopes per-agent provider out; non-Anthropic stays on the tier table. Schema still carries `modelProvider` (derived from the catalog entry) for forward-compat.
- **Y — Combined "model+harness" preset dropdown** (one `Select` like "Opus on Claude Code"). Rejected: collapses two orthogonal axes (brain vs body) into a combinatorial list (4 models × N harnesses), and breaks the moment a harness leaves the PATH. The concept's rejection list explicitly separates harness from model.
- **Z — Remove Settings → Models entirely.** Rejected: the Scheduler's cost-posture downgrade (`docs/agent-layer/model-routing-and-cost.md` §6.3) and the no-per-agent-model fallback both need the tier→model mapping. Concept chose "demote, not remove." Removing it would strand `resolveModelTier()`.
- **W — Free-text harness with an autocomplete/typeahead of registered types.** Rejected: still permits a non-matching submitted value (the exact defect AH2 closes) and the concept hard-rule forbids any free-text path. A plain constrained `Select` is simpler and cannot produce an invalid value.
- **V — Modal dialog for agent edit instead of inline row expansion.** Rejected: the existing surface is inline-expand; switching to a modal is scope creep with no task benefit and would diverge from `AgentEditDialog`/`SettingsAgents` conventions.
