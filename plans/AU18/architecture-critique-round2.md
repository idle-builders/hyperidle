### CRITICAL (new or still-open)
- **[§3 template row / §10 Q2, AC-5] The locked docs-read design breaks behavior-preservation on a live, web-facing template path.** `factory-bootstrap.ts:188-197` seeds `system_template:<role>` rows for roles **`product_manager`, `facilitator`, `builder`, `growth`, `designer`, `qa_engineer`, `ops`** via an explicit **role→filename map** where the filenames are hyphenated and role≠stem (`product_manager`→`product-manager.md`, `qa_engineer`→`qa-engineer.md`). The web client requests these live: `AgentEditor.tsx:161` and `AgentAddDialog.tsx:84` call `GET /api/agents/templates/${role}` with the agent's `role`. Today `GET /templates/product_manager` returns the seeded content (200). The revision **locks** two incompatible details: (a) §3 the validation regex `^[a-z][a-z-]*$`, which **rejects the underscore** in `product_manager`/`qa_engineer` → 400/404; and (b) §10 Q2 resolving `docs/system-prompts/${role}.md`, which yields `product_manager.md` — a file that **does not exist** (the file is `product-manager.md`) → 404 even if the regex passed. Either way the PM/QA/etc. template reads regress from 200 to 404 — an AC-5 violation on a path the web UI actually hits. Compounding: the plan asserts "the canonical role set lives in `factory-roster.ts` (`templateRole`)", but every `templateRole` value there is literally `"facilitator"` — it does **not** enumerate `builder`/`growth`/`designer`/`product_manager`/`qa_engineer`/`ops`. The true canonical role→filename source is the `factory-bootstrap.ts` array. Fix: the shared helper must reuse bootstrap's explicit role→filename map (not naive `${role}.md`) and allow the real role charset (underscores), or allowlist against that bootstrap array — and the plan must stop naming `factory-roster.ts:templateRole` as the role source. Also note a name/signature collision: bootstrap already has a `readSystemPromptTemplate(docsRoot, filename)`; the plan proposes a new shared `readSystemPromptTemplate(role)` — same name, different signature — which must be reconciled, not duplicated. This is mechanically small but is a **locked** decision that ships a regression as written, so it must be fixed at the plan level, not left for the builder to discover.
