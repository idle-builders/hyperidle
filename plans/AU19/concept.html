3

Enforcement — three mechanisms, general not per-domain

AU17 proved the technique (an unexported cross-package import genuinely fails tsc module resolution). AU19 applies it at the right grain, adds the ACL half AU8 was for, and closes a third gap neither of the first two covers: nothing stopped one Service from just importing another.

Mechanism A — Table ACL
A SQL‑owning Service's barrel never exports its raw table object — no other package can obtain a reference to it. One small general guard checks every barrel, replacing the 9 separate hand-typed per-domain guards AU12–AU18 each wrote.
Mechanism B — Execution boundary
Only agent‑execution's Service packages may import an LLM CLI, harness adapter, MCP bridge, or tool‑execution symbol. Every other package is structurally forbidden — nothing depends on them.
Mechanism C — Composition boundary new
A Service package's dependencies are only db/shared — never another Service, never a Layer. Wiring is a Layer's job composing its own Services, and an Application's job composing Layers. A Service does none of its own wiring.
Worked example — why this matters
context‑assembly (an agent‑orchestration Service) needs Knowledge to build a run's context bundle.
✗ Forbidden
// context-assembly/src/index.ts
import { getItems } from '@hyperidle/knowledge'
A Service reaching into a neighbor on its own. This is exactly how a "weird feature" appears — nothing named it as wrong.
✓ Required shape
// context-assembly/src/index.ts
export function assemble(reader: KnowledgeReader, ...)

// agent-orchestration/src/index.ts (the Layer)
import { assemble } from '@hyperidle/context-assembly'
import { getItems } from '@hyperidle/knowledge'
assemble({ getItems }, ...)
The Layer package composes both Services. context‑assembly never imports knowledge — it takes it as a parameter.
Not a new pattern: this is the same shape the AU12/13 join‑decomposition precedent already used — findRetroItemByThreadIds (work) + getThreadIdsByHost (conversation) were combined by the route handler (core‑api Layer code), not by one Service importing the other. Mechanism C just makes that mandatory everywhere.
