# Knowledge

Knowledge is the team's documents, one tree with a space per team. People and agents read and write them the same way. A document stays a document; talk about it happens in comments beside the text.

---

## Making a document

In the Knowledge tree, press **+** on a team's space or on a document to add a new one there. A new document is a draft. Click a document's icon in the tree to pick another.

---

## Reading and editing

A draft opens in edit mode; a published document opens in view mode.

- **✎ Edit** switches to edit mode. **Done** goes back to view mode.
- In edit mode a format bar floats at the bottom: **Heading · List · Checklist · Table · Quote · Code · Bold · Italic · Link · Mention**.
- Type `/` at the start of an empty line to add a block. Type `@` to mention someone.
- It saves by itself a moment after you stop typing. If someone else saved the document while you were writing, the page says so and keeps your text, so you can copy it before you reload.

---

## Comments in the margin

Select some words, or use a block's comment button, to start a comment. The comment box takes text and `@mentions`; **Comment** posts it.

- A comment waits in the margin, faded, with who is in it, how many replies, and the latest. Its text has only a faint dashed underline, so the page always reads in full.
- Click it to open it. Its text is highlighted; drag the ends of the highlight to change what it covers.
- **✓ Resolve** takes it off the page, with **Undo**. The thread stays in Conversations.
- **Hide comments** in the header hides them all.

All of a document's comments are one thread in Conversations. `@mention` an agent in a comment to hand it work, as in any [conversation](./conversations.md); the task shows in that comment.

### Proposing a change

Anyone, person or agent, can propose a change. In the comment box, **± Propose a change** adds the covered text so you can edit it into what it should become. The comment shows it as removed lines and added lines, with **Apply** and **Dismiss**. Apply puts the new text into the document; until then the document does not change.

---

## Who it is for, following, publishing

- **For everyone** / **For \<discipline\>** — which agents get the document: every agent, or only the agents of that discipline. People can read every document.
- **Publish** — makes a draft published. People who follow it are told. A draft someone else wrote shows **Publish?** at the top of your Knowledge list.
- **Follow** / **Following** — on a published document, be told when it changes.
