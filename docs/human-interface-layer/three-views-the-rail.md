## 2. Three Views

The factory is Slack + Linear + Notion in one app. Each view maps to a well-understood tool category, simplified and opinionated for AI-human collaboration:

| View | What it is | Industry parallel | Key objects inside |
|---|---|---|---|
| **Conversations** | Messaging, reviews, conversations | Slack, Teams Chat | Threads (review, chat, assistant) |
| **Work** | Planning and tracking | Linear, Jira | Bets, Tasks |
| **Knowledge** | Wiki — catalogue of knowledge items | Notion databases, Confluence | Topics, knowledge items |

Ambient awareness surfaces are embedded within each view: Conversations filter chips surface triage state, WorkTeam AgentRow health indicators show agent status, and the Sidebar triage badge shows unread count. The assistant's thread is a pinned thread in Conversations, not a separate surface.

Within each view, easy-to-understand objects create the complexity necessary to make it useful.
