# Journey Gap Registry (Wave 4)

Source: bucket-A, bucket-B, bucket-C, bucket-D reports
Raw gaps: 169 → clustered to 28 → pruned 14 (kept in pruned.md)

Method: deduped across buckets, clustered around the underlying missing thing, ranked by composite score (Major-rank weight × severity × frequency × blast radius, with +1 trust bump for safety/recovery affordances). Lowest rank number = highest priority.

Action class legend: `data-shape` (schema/contract), `route-add` (new route + page shell), `affordance` (UI element + handler on existing surface), `flow` (multi-step orchestration / wizard / draft state), `recovery` (safety / undo / kill-switch), `responsive` (breakpoint / viewport), `discoverability` (entry point / nav fix).

### Top 10 single biggest leverage cluster fixes

1. **Thread list / queue rendering (rank 1)** — Unlock every triage journey at step 1 (DL-02, DL-09, DL-21/22, DL-16, ADV-01) and make the Submenu's section headers honest. The literal core daily loop becomes possible.
2. **Post-commit verdict undo (rank 2)** — Eliminate the fat-finger trust hazard and align mouse/keyboard semantics; once present, every approval-recovery journey (RE-01..RE-04, RE-25) gains a first-line safety net.
3. **Mobile breakpoint (rank 3)** — Restore the rank-8 Major journey and ADV-03; without this the "phone-first morning rhythm" promise of the product is broken at 390px.
4. **Request-Changes composer + inline anchor (rank 4)** — Make the most-used non-approve verdict actually function; restores the inline-anchored trust mechanism that defines proposal review.
5. **Recovery verbs (kill/rollback/mid-session pause) (rank 5)** — Add the safety net for autonomous agents; the kill switch the architecture explicitly requires "from day one" and the rollback path for irreversible actions both come online.
6. **Rail interactivity bridge (rank 6)** — Turn ambient awareness into actionable navigation; "Rail → Conversations bridge" stops being a label and starts being a link, and a 10s glance becomes possible.
7. **Artifact-kind renderers (rank 7)** — Unblock six Major journeys at once (DL-05, DL-19, RE-03, RE-04, RE-05, RE-25); without distinct renderers, every high-risk approval renders identically to a low-risk text_diff.
8. **First-run flow (rank 8)** — Make a fresh install actually usable by a real founder (today it's only usable because of seeded SQLite); enables FR-01, FR-02, FR-03, FR-12 simultaneously.
9. **Coach / CoS thread (rank 9)** — Bring online the only systemic-improvement surface and the load-bearing trust-compounding mechanism; pinned-thread pattern starts working.
10. **Missing route shapes (rank 10)** — Unblock four Major journeys at once (DL-14/15, DL-17/18/RE-15, PU-07, FR-07/08/10) by adding `/work/product/:id`, `/work/team/:id`, `/work/agent/:id`, `/work/task/:id`. Most leverage per route added.

### Cross-cutting observations

- **The app is a pre-implementation skeleton that renders state but rarely accepts input.** Of 169 raw gaps, ~70% are missing affordances on existing surfaces (write side absent, read side present), not missing surfaces. The pattern is consistent across cost (read tile, no editor), autonomy (read select, wrong shape), bets (read detail, no decisions), knowledge (read item, no version). Implementation strategy should bias toward "add handlers/forms to existing pages" rather than "build new pages."
- **Schema mismatches will cause expensive rework if not fixed first.** Two clusters (rank 12 autonomy, rank 14 founder-routing) are pure data-shape problems where the current types cannot encode the spec. Building UI on top of the wrong shape compounds the cost — fix the shape before any UI work that consumes it. `AutonomyLevel` and the missing `actor` concept are the two highest-leverage type changes.
- **Recovery surfaces are entirely absent and disproportionately dangerous.** 5 of 8 Major recovery journeys in bucket C have no entry point at all. The factory kill switch — explicitly called "users need to know exists from day one" — does not exist. Mouse-click verdicts commit irreversibly. Without the safety net, every autonomy concession the founder grants is unsafe; this gates trust compounding for the entire product.
- **Mobile is structurally absent, not just degraded.** The codebase has only two desktop breakpoints. There is no mobile layout to polish — a three-tab nav, bottom-tab pattern, and thumb-reachable verdict surface have to be built from zero. This is responsive work, not styling work.
- **Multi-step / stateful flows have no host in the router.** Sunset (PU-07), bet selection commit (PU-14), three-way merge (RE-13), and first-run (FR-01) all need draft state that survives navigation. The router has no `/wizards/*`, no draft model, no session-store concept. This is one missing primitive blocking five journeys.
