## Open questions

- **In-app help / support recovery.** No mention of how a confused user gets help. Is there a `?` shortcut, a Coach-help mode, a docs surface? Probably needs a journey but couldn't confirm scope.
- **Network loss / offline mobile.** Mobile is "online-first" by decision. What does the user see when the connection drops mid-approve? Optimistic with rollback, or hard-fail toast? Underspecified.
- **Account recovery / lost-device.** Tailscale-only access by default. What happens when the founder loses their device or Tailscale auth? Out of UI scope or a Settings flow?
- **Agent rebellion / loop detection.** Spec implies the meta layer tracks cost and trajectory but doesn't describe what the human sees when an agent is detected to be looping or "lying" in session notes. Should there be a dedicated "agent health" surface or does it route to Conversations as a blocking review?
- **Knowledge import/export rollback.** Settings mentions import/export. What happens when an import corrupts the knowledge store? Suspect a "restore from snapshot" journey exists but is not specified.
- **Cycle phase advance regret.** Founder advances Cool-down -> Shaping; pitches archive. Is there an undo? Currently no journey defined for "I advanced too early."
- **Cross-team task gridlock.** When a providing team refuses or is over-cap, the requesting bet's task stalls. The current flow assumes goodwill — no journey for "escalate gridlock to Chief of Staff."
- **Founder-disagreement recovery.** CEO and CPO post conflicting verdicts on the same review thread (both are listed approvers). Spec doesn't define the conflict resolution journey.
