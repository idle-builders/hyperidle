## Open questions

- **Team-level retros visibility** — agents auto-fire retros (F-9.1) routed to Practice + Coach. Does the founder ever directly browse retros, or only encounter them via the Coach thread? If yes, an entry point on the bet detail or portfolio is missing.
- **Cycle phase advancement** — UX-5.8 says founder triggers Shaping → Betting → Building → Cool-down. Is this a per-product or factory-wide action? The journey to "advance the cycle" deserves explicit treatment.
- **Founder-to-founder handoff** — CEO and CPO have distinct routing (F-6.4). Is there a journey for "delegate this review to my co-founder"? Likely yes; not covered above because docs don't yet specify the affordance.
- **Knowledge import** — settings mentions import/export (UX-8.3). Is import a real journey (seeding from prior tooling) or only theoretical? Strongly suspect rare-but-high-value at first install.
- **Skill authoring vs. approval** — humans approve skills (S-4.4) but where do new skill drafts come from? If founders ever author skills directly, that's a missing journey.
- **Agent observation / debugging** — when an agent misbehaves, the founder may want to inspect a session, replay it, or open the workspace. Not covered in any view; possibly belongs to a developer surface, not founders.
- **Audit / compliance review** — quarterly, a founder may want a "show me every irreversible action approved this quarter" report. Not present in current views.
