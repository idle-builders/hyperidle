- [Our Components](./our-components.md) — four-tier composition model, shipped component set, DaisyUI as-is list, and the Tier-2-vs-Block-primitive naming disambiguation.
- [Rules](./rules.md) — eight non-negotiable rules governing wrapping, density, theming, scroll, and heading discipline.
- [Page Anatomy](./page-anatomy.md) — PageHeader/SectionLabel scaffold, heading-level contract, and the two lint rules that enforce it.
- [Settings Consistency](./settings-consistency.md) — AG7 design contract for Settings sections: card/flat/flush rules, spacing grid, StatusChip color semantics, static gate, and descriptor-driven harness section.
