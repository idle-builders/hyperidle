### Summary

- Dead / speculative abstractions: `AsyncFsAdapter` + factory, unused `GitRunner` methods (log/status/remoteV/symbolicRefHead/fetch/resetHard/revParseHead), `_now` parameter, `createRunnerFor`, `freshlyInitialized` field, `KnowledgeRow` interface, `GIT_EXPORT_SETTING_KEYS` alias.
- Enterprise smell: the `GitRunner` interface bloats into a near-full git wrapper for a service that needs ~6 verbs.
- AI tell-tales: "1./2./3./4./5." step comments, `// ---` banners, RED-phase preambles in test headers, "Async variant — unused" doc.
- Real bugs: `c.req.valid("json" as never)` violates the no-unsafe-cast rule; `repoPath || "/tmp"` fallback in the route; silent `try/catch` swallow in `writePlanToDisk`; the concurrency test can't fail.
- Duplication: `loadGitExportConfig` vs `readGitExportConfig` (~95% overlap); commit-wrap logic duplicated instead of reusing `runExpectOk`; inline `FsAdapter` copy-paste in integration tests instead of `createNodeFsAdapter()`.

Severity mix: 0 critical, ~10 major, ~20 minor, ~5 nit.
