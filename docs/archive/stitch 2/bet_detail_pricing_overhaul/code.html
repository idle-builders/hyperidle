Strategic Pitch

The current pricing engine rounds to the nearest cent, but our contracts specify four decimal places for precision-based billing in the enterprise tier. This discrepancy is causing minor but persistent drift in month-end reconciliations.

Rabbit holes

Don't try to backfill historical invoices. The delta is negligible and the risk of breaking ledger integrity is high. Focus solely on forward-looking calculations.

Done means

  • All new invoices calculate to 4 decimal places.
  • Pricing API returns unrounded values to consumers.
  • Regression suite validates rounding logic against 10 distinct edge-case contracts.
