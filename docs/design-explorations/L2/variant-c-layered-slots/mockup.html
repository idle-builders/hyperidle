Block ingestion contract

Blocks are derived during ingestion, never stored as a custom dialect. The on-disk format remains GitHub-flavoured markdown — agents write GFM, the watcher copies bytes, and the renderer projects blocks on read. Identity is a structure-aware blake2s_128 hash; see BLOCKS.md §8.4.

  • Round-trip from on-disk → derived → rendered is lossless
  • Re-derivation preserves ids when content + outline path are unchanged
  • Threads survive their target block's deletion as a "block deleted" indicator
    • Re-anchor on next edit
    • No data loss
Why a 128-bit hash?

At the realistic ceiling of (bodies × blocks-per-body), collision probability is below the threshold of any incident we will field. Bumping the version tag (blk:v1 → blk:v2) is the migration handle.
